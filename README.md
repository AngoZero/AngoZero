### Qué construyo

Diseño y programo el ecosistema **Angou**: SaaS multi-tenant para PyMEs mexicanas.
Del esquema de base de datos al despliegue: arquitectura, backend, frontend, infraestructura y operación.

| Producto | Qué resuelve |
|---|---|
| **angoshop** | E-commerce y punto de venta multi-tenant. Catálogo, pedidos, inventario, caja. |
| **angoranch** | Gestión de ranchos ganaderos. Ciclo productivo, hato, partos, ventas. |
| **[angovaro](https://angovaro.angou.com.mx)** | Finanzas personales y grupales. |

### Open source

Piezas del ecosistema que liberé para que cualquiera las use:

- **[angou-security-laravel](https://github.com/angouhq/angou-security-laravel)** — capa anti-bot para Laravel: honeypots, bloqueo de correos desechables, timing humano, Cloudflare Turnstile, fingerprinting de user agent.
- **[angou-security-react](https://github.com/angouhq/angou-security-react)** — los componentes React que la acompañan: `<TurnstileWidget>`, `<HoneypotField>`, `useFormTiming`, `secureFetch`.

<br>

I design and build **Angou**, a set of multi-tenant SaaS products for small and medium businesses in Mexico. I work across the whole stack — database schema, backend, frontend, infrastructure and operations.

| Product | What it solves |
|---|---|
| **angoshop** | Multi-tenant e-commerce and point of sale. Catalog, orders, inventory, cash register. |
| **angoranch** | Cattle ranch management. Production cycle, herd, births, sales. |
| **[angovaro](https://angovaro.angou.com.mx)** | Personal and shared finances. |

**Open source** — pieces of the ecosystem I released for anyone to use:

- **[angou-security-laravel](https://github.com/angouhq/angou-security-laravel)** — anti-bot defense layer for Laravel: honeypots, disposable email blocker, human timing checks, Cloudflare Turnstile, user agent fingerprinting.
- **[angou-security-react](https://github.com/angouhq/angou-security-react)** — the matching React components: `<TurnstileWidget>`, `<HoneypotField>`, `useFormTiming`, `secureFetch`.

Mostly Laravel, PostgreSQL, TypeScript, React, Astro and Docker. Most of my work lives in private repositories under [angouhq](https://github.com/angouhq).
